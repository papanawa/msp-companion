# MSP Companion
### Alerts. Tickets. Resolved.

Unified Datto RMM + Autotask PSA platform with AI triage.  
Built by Synobis Network Solutions · Powered by Claude AI.

## Setup
1. Configure credentials in Settings
2. Click Refresh All to load live data
3. Install as PWA from Edge/Chrome for desktop app experience

## Resolution Flow
Alert Seen → Ticket Created/Linked → Work Ticket → Post Resolution → Resolve Alert → KB Logged
